## 六個策略：每步只增加一項可解釋變化

1. `EMA_CROSS_90`：EMA9/21新交叉入場，相反新交叉退出，持倉最多90分鐘。
   1m案例與原版逐筆會計／成交／盈虧等價；原本啟動第一bar不補做訊號。
2. `EMA_CONFIRM_90`：相同入場，離場改為連續兩根已收市bar的EMA9−EMA21
   均反向超過0.25×各該bar ATR14；不是一次小交叉立即退出。
3. `BREAK_TREND_CROSS_90`：收市价首次突破前20根高／低（不包括當根），
   EMA9/21方向及EMA9斜率同向，ER20≥0.20；交叉離場、90分鐘。
4. `BREAK_TREND_CONFIRM_90`：同3入場，改為2的確認離場。
5. `BREAK_TREND_CONFIRM_360`：同4，只延長最多持倉至360分鐘；**止損始終生效**。
6. `BREAK_TREND_CONFIRM_360_SPACE`：同5，但只在過去20bar高低範圍／最新收市價
   ≥止賺距離/0.8時准許入場。這是已觀察幅度過濾，不是未來波幅預測。

**主觀察事前固定為5m的第5項，全段15日。**不會因其他候選結果較好就換主角。
6策略 × 2成本 × 2路徑 × 11粒度/窗口 = **264個情境**，全部保存，無參數優化。

EMA在每次120根已收市序列從第一個收市價開始遞推，與原版一致。
ATR14是最近14個真實波幅的簡單平均；確認離場的前一bar用其自己的ATR。
ER20=abs(Ct−Ct-20)/sum(abs(20個逐bar變化))，分母0時為0。
突破必須由前一bar未突破其相應前20bar範圍，變成當根突破；不重複追價。

## 成交與成本：不為了通過而降低門檻

沿用基本費率每邊0.045%、假設整個spread 1bp、每邊不利slippage 1bp；
壓力情境為0.09%、3bp、3bp。後者不是平台實際費率聲明。
目標10.10USDC、最低10、2x虛擬保證金、名義上限餘額1.15倍、現金預留3.50。
預估單筆風險≤餘額1.25%，止損max(0.3%,1.5×ATR/close)，超過1%跳過，目標1.8倍。
**目標≥來回模型成本3倍的閘保留**；不強行放大止損／刪除成本以產生成交。
同時最多一倉、24小時最多6次開倉、平倉後冷靜15分鐘、連敗3次永久暫停。
止損、止賺、回撤停機優先於確認訊號與90/360分鐘時間退出。

每根bar假設在+2秒觀察open，在35%和2/3時間處觀察高/低，再於末尾前2ms
觀察close；另測高低相反順序。只有open取樣讀取之前已收市的120根bar。
為了適配原生bar，**歷史適配器的gap容忍期按bar長度調整**；這不是放寬live
故障風控。缺任意原生bar直接拒絕，沒有假造中間1分鐘、L2或延遲。
粗粒度行情不會完整捕捉bar內價格來回、真正止損次序、極短跳價等風險。

funding只按持倉跨過的歷史結算事件計算，使用事件之前已收市原生bar價格
代理oracle，不能稱精確結算價。每個整點費率都必須齊全；事件代理太舊、
未核對funding或期末仍持倉時不能產生有效績效結論。

## 新補資料及診斷

- 1m／5m／15m固定OHLCV與成交筆數、覆蓋完整的歷史funding、市場數量精度。
- 同一範圍第二次下載與第一次核對；raw位元組／請求／正規化逐欄核對。
- 完整重疊1m聚合成5m、5m聚合成15m，核對官方原生OHLC；不是第二獨立來源。
- 一次當前L2 spread快照只作現況參考，**不回填歷史spread、不用它調参**；
  此附加請求失敗不假稱已取得，歷史核心資料仍須完整。
- 盈利筆數、淨勝率、名義95% Wilson（IID假設）、平均淨利、平均贏輸、profit factor、
  spread/slippage、手續費、funding、相同交易的高成本反事實、取樣回撤、持倉時間、
  期末強制平倉數、停機時間、訊號與拒單原因、stop floor比例、目標／成本比例。
- 停機後可計算的訊號數只列diagnostic，不當成原帳戶後來的交易或盈利。

0交易的勝率為undefined，不是0%也不是成功。+5%回報與55%淨勝率分開。
即使觀察值≥55/60，也要檢查樣本、跨窗口穩定性、成本壓力及多重比較；
少於100筆交易會明示樣本不足，不宣稱已取得未來55/60勝率或收入來源。

## 安全、驗證、交付

唯一網絡client沿用原TLS驗證、禁止redirect、最大回應大小、最多3次有界重試；
只擴展白名單的ETH 5m/15m candle與一個公開ETH L2讀取。无account/order端點。
獨立驗證器不import交易engine，另算全量特徵、入場／訊號離場原因、數量、
成交、費用、funding、淨值與取樣回撤。1m基線等價、未來污染、確認離場仍止損、
原生時間尺度、永久停機、缺資料與失敗不報成功等有離線測試。
人工fixtures只作軟件測試，不當成歷史績效或隨機生成賺錢數據。

Actions為一個prepare、三個普通VM時間尺度分片、一個aggregate，各≤25分鐘。
只讀權限，不persist checkout credentials，沒有排程、付費服務、merge或部署。
source/protocol/run/attempt/data hashes不符、任何分片缺失均拒絕全批成功。
原始data/第二次下載/checks/source/tests在prepared artifact；264行CSV、完整
交易帳目、summary及report在final artifact。舊PR和Issue保持，不開新Issue。
