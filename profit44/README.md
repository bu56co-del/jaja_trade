# A44：改善淨收益的對照實驗

本批沿用 Issue #1／PR #2。目標是針對上批回踩0.50＋EMA20/50的失敗機制，測試**較早確認、結構止損、收益距離及剩餘價格空間**；不是保證提高將來賺錢機率。

## 固定資料與成本

只使用上批 `falsebreak44-final-35525531802-1` 的原始A44輸入。以 `reversal44/dataset_index.json` 核查原58檔hash，精確選A類44日、63,360根1m，不含B/C類日期。實際相鄰日期形成27段；每段首120根5m（10小時）只預熱，執行47,160分鐘。不同段各自是一個獨立10 USDC實驗，不跨缺日持倉，不每日重設，不把27段加總當成一個10 USDC戶口複利。

沿用原有基本與壓力成本、1m四個假設時點、兩種OHLC路徑、保守止賺封頂、前收市價funding代理。最高單筆計畫損失仍是現金1.25%，止損距離上限1%，單倉、最低名義單額10 USDC、目標單額10.10、名義額/淨值1.15上限、2倍保證金參數、3.50現金預留、三連敗與5%回撤停機、15min冷靜期、6筆/24h與360min最長持倉均不變。

**本輪不作maker成交假設、不減費用、不加槓桿、不刪虧損、不取消停機。**保守target cap屬成交模型調整，不是額外交易所費用；模型止損保留不利超價。

## 24個固定組合

2入場 × 2止損 × 3止賺R × 2空間要求＝24個，其中一個是原版對照，23個新候選。每個測2成本×2路徑×27段，共2,592情境。主觀察事前固定 `EARLY_STRUCTURE_R2.5_ROOM`，不會因失敗而事後換主角。

### 入場

共同部分完全沿用上批回踩0.50＋EMA20/50：前20根已收市5m高低定區間，越界且收市在界外0.10ATR才形成事件，前6根反向極值A及事件bar極值E固定；只等其後12bar，回到固定 `(A+E)/2` 附近0.15事件ATR，再等不同一根bar（觸碰後最多2bar）收市穿過觸碰bar高/低、實體與EMA20/50方向及快線斜率同向。

- `BOUNDARY`：沿用原規則，確認收市同時要回到原突破邊界外。
- `EARLY`：只取消上述最後邊界要求；收市必須已重新越過0.50回踩價，並通過其餘確認。較早並非在touch bar、未收市bar或回踩價上假設成交，仍在下一根1m的假設+2s開市取樣成交。

事件過期、觸碰過期、收市穿過原A錨點均取消；每事件至多一個訊號。EMA拒絕的事件也不反覆補做。多空對稱。

### 止損

設入場方向d∈{+1,-1}、模型入場價P、目前已收市ATR a、收市價C、事件ATR a0。

`ATR`: f0=max(0.003,1.5a/C)，沿用原版。

`STRUCTURE`: 找觸碰bar至確認bar（含端點）已知最低L／最高H；多方結構失效價 S=L−0.15a0，空方 S=H+0.15a0；f=max(f0,d(P−S)/P)。止損價=P(1−df)。結構價若在錯誤一邊，或距離/含成本風險超過原限額，直接拒絕。

沒有把結構距離冒充ATR輸入引擎。保存實際ATR、結構失效價、計算距離、原ATR止損和選定距離供獨立驗算。止損不比原ATR版更近，但也不放寬帳戶資金風險。

### 收益距離與價格空間

固定R∈{1.8,2.5,3.0}；目標=P(1+dfR)。R較大只是目標，不能假定會達到。

`NONE`: 不增加入場過濾。

`ROOM`: d(E−P)/P ≥ f+估算來回成本。要求價格回到**事前已固定的舊極值**前，至少仍有一個止損距離加成本的空間。這不是預測未來最高/最低，亦不等於一定能到舊極值或止賺價。

## 對照與判讀

`BOUNDARY_ATR_R1.8_NONE` 必須重現上批 `RETEST_0.5_20_50` 的108個經濟/交易情境：同進出時點、成交、数量、費用、funding、止損止賺、halt、回撤及metrics。只有策略名稱與新增診斷欄位可不同。

主要比較：基本成本總淨利、固定原交易加高成本、重新以高成本過入場門檻、平均每筆淨利、profit factor、淨勝率/筆數、正負/無交易片段、回撤及拒單原因。高成本重跑可能換交易，不冒充同交易只加成本。

加總淨利/270×100 是平均片段回報，不是單一戶口連續回報。所有24個候選一同披露，虧損/零交易不省略。某個版本在已看過資料上轉正，只能稱為本次歷史模型正數，不能称為穩定收入或較高將來成功機率已被證明。

## 證據及安全

因果訊號與特徵由獨立前向搜尋參考算法核查。驗算器不import交易引擎，逐筆核對風控/入場/退出，重建每個持倉觀察時點的現金、funding、最早止損止賺/時間退出及回撤/停機。另保留54項人工單元/整合/變造測試。測試通過不等於策略盈利。

不改既有模組；只新增 `profit44` 和指定workflow。一次有界執行，4個25分鐘普通runner研究job，無schedule/循環dispatch、無新市場API、無錢包或帳戶資料、無任何真實/testnet訂單、無付費服務、無merge/main寫入/發布。GitHub artifact保留7日，不稱永久保存。

重現：在repository先 `python3 bootstrap.py`，restore上批artifact到`previous`，PYTHONPATH加上 `application:application/tests:longer:execution:reversal44:profit44`，再執行 `python3 profit44/run_profit.py --group 0 --previous previous --out group-output`；其餘group為1–3。需新輸出目錄，不讀上次成功summary作本次結果。
